Documentation 02 - Visual directions Decision needed

Visual directions

Three complete directions, each rendered below with its real typefaces and palette rather than described. All three use the specified orange, pink and light neutral, and all three read as "space" - they differ in what kind of space, and therefore in what kind of studio Starship Suits appears to be.

In use: Direction A, provisionally The live coming-soon page at web/index.html is built in Direction A, on the reasoning in the recommendation below - it is the only one of the three that works before the studio has professional photography. This is not a final commitment. Every visual value is a CSS custom property in :root plus one @font-face block, so switching to B or C is a token swap, not a rebuild. The full comparison still stands; read on.

One thing the build settled that the mockups did not: measured contrast against the bone background. Ink is 15.67:1 and safe anywhere. Orange is 3.21:1 - it passes for large display type only, and fails for body copy. Pink is 2.75:1 and fails even at large sizes, so it is restricted to decorative shapes and must never be used for text. Directions B and C need the same measurement before they ship.
How to choose Do not pick on prettiness. Pick on the answer to one question: which of these makes a buyer comfortable spending $8,000 and waiting four months? Each direction answers it differently - A by looking meticulous, B by looking expensive, C by looking friendly. All three are defensible. The rest of the build follows from this choice, so it is worth an afternoon.

Direction A - Mission Patch

Apollo-era print. Warm bone paper with a halftone dot texture, heavy extended type set in uppercase, embroidered-badge geometry, and prices laid out as a perforated ticket stub. The space reference is printed matter - mission patches, checklists, flight manifests - not outer space itself.

StrengthsRisks
Reads as meticulous and technical, which is exactly the reassurance a $8,000 buyer wants. Translates directly to merch - patches, stickers, hang tags, business cards - so the brand extends past the website for free. The light background frames suit photography without competing. Cheapest of the three to produce well. Retro-NASA is a well-worn aesthetic; executed lazily it looks like a t-shirt template. Uppercase extended type is unforgiving of long words and can get shouty. Least overtly "furry" of the three - risks reading as an aerospace consultancy if the photography is weak.

Direction B - Deep Space Vitrine

Dark editorial. A near-black plum void with a soft nebula bloom, an asymmetric grid, and a high-contrast wonky serif. Photography is the hero and everything else recedes; orange and pink appear only as rim light, gradient text, and a single hairline rule. The space reference is the void the object floats in.

StrengthsRisks
Most obviously premium - it justifies the top of the price range on sight and is the only direction that makes a $12,000 suit look like a $12,000 suit. Saturated fursuit colours pop hard against near-black. Neither reference studio looks anything like this, so it differentiates instantly. Entirely dependent on photography. Dark editorial layouts have nowhere to hide a badly lit snapshot - this direction is only viable with properly shot work on clean backgrounds. It is also the coolest in tone, which sits slightly against the warm, personal character of the fandom, and the least merch-friendly of the three.

Direction C - Cockpit

Playful retro-futurist toy. Cream base with a pink starfield dot grid, chunky rounded display type, helmet-visor shapes, rotated sticker badges and hard offset shadows. Everything is tactile and slightly over-inflated - the page has the same proportions as the product. The space reference is a toy rocket ship.

Recommendation

Direction A, if the studio has no professional photography yet; Direction B once it does. A is the safest bet with the widest margin for error, it costs the least to build well, and its mission-patch geometry gives an immediate logo and merch system - which a new studio needs more than a beautiful homepage. B is the stronger site, but it is a photography project wearing a web design, and commissioning it before there is work to photograph would be building the frame before the picture.

C is the right answer if the studio's actual character is loud and funny. That is a question about the owner, not about design, and it should be answered honestly rather than aspirationally.

If a direction is picked

The chosen direction becomes a token set and a component library before any page is built:

  • Tokens - colour, type scale, spacing scale and radii as CSS custom properties in one file.
  • Fonts self-hosted - subset WOFF2 files committed to the repository. The live site must not load fonts from Google's CDN: it would breach the site's own default-src 'self' policy, add a third-party dependency on the render path, and leak visitor IPs to a third party. These planning documents use the CDN because they are internal and never published.
  • Components - navigation, tier card, portfolio tile, gallery lightbox, enquiry form, footer. Built once, reused by every page in document 03.
  • Accessibility pass - all three directions need contrast verification before shipping. Orange on light is the risk in A and C; the muted body text on void is the risk in B.
